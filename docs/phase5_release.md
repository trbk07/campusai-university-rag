# Phase 5 release status — Citation, Grounding and Abstention

## Implemented

- Request-scoped `EvidenceRegistry` with immutable chunk/page/source metadata.
- Quote fidelity validation using NFC and whitespace normalization.
- Deterministic atomic claim extraction and claim/evidence alignment.
- Exact numeric/code marker checks to prevent unsupported-value leakage.
- Stable abstention taxonomy with user-safe Vietnamese/English messages.
- Recomputed confidence score (`phase5-v1`) from retrieval support, claim
  entailment and citation completeness; provider confidence is not trusted.
- Phase 5 schema metadata and cache invalidation versions.
- Gold-based grounding metrics for claim precision/recall, claim-citation
  precision/recall/F1, citation precision, completeness, abstention
  precision/recall, reason accuracy, ECE and Brier score.

The Phase 5 layer preserves the Phase 4 public fields and legacy reason values
for compatibility. Public responses use the v2 `PublicResponse` contract;
`InternalGroundingTrace` carries evidence status, confidence score, claim
support status and policy/schema versions inside the application boundary.

## Release gate

The implementation gate is in place, but a final 10/10 evidence claim still
requires an independently annotated Phase 5 benchmark of at least 400 records
with dev/test/holdout splits. Reports must be generated by
`evaluation/metrics_grounding.py` and checked with
`evaluation/validate_phase5.py`; hand-edited pass flags are not accepted.
